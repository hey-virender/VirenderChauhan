## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/hey-virender/VirenderChauhan.git
```

### Navigate to Project Directory

```bash
cd VirenderChauhan
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Visit:

```bash
http://localhost:3000
```
